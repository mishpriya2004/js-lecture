## Installation of react

1. Check node version => node -v
2. npm create vite
3. Give Y (first time only)
4. Select react and enter
5. Select javascript and anter
6. Asked for install packages : give yes
7. Move to project folder
8. If you have give no ans in step 6 then first hit the command npm i
9. Hit the command npm run dev -> start project 
10. Open the link in browser -> http://localhost:5173
